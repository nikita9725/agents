# agents
AI-агент на Python для многошагового выполнения задач на базе LangChain, LangGraph и LangSmith. Планирует действия, вызывает инструменты, управляет состоянием и проверяет результат. Графовая архитектура обеспечивает контроль выполнения, обработку ошибок и защиту от зацикливания, а интеграция с LangSmith — трассировку каждого шага.
