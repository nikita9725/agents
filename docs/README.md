# Документация проекта

Агент составляет краткий план диагностики ETL, последовательно вызывает инструменты,
учитывает observations и сохраняет историю. День 3 разделяет planning, acting, tools
и observation; trace доступен через API, SSE и пример клиента.

- [Планирование](planning.md) — контракт модели, prompt, ограничения и настройки LLM.
- [Граф выполнения](graph.md) — схема, узлы, состояние, бюджет и сценарии ошибок.
- [История запусков](history.md) — PostgreSQL, checkpoints и чтение после перезапуска.
- [API задач](api.md) — task_id, фоновые задачи, SSE и отмена.
- [Наблюдаемость](observability.md) — локальные логи и LangSmith.
- [Тестирование и качество кода](testing.md) — пирамида тестов, контейнеры, pre-commit.
- [Архитектура и окружение](architecture.md) — официальный DBOS/PostgreSQL, сборка из uv.lock, Compose и команды.

Начало работы: [README проекта](../README.md).
